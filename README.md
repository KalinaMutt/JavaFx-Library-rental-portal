# JavaFx-Library-rental-portal
An application for library customers  to rent books and dvds as well as an admin portal for staff to check rental records and update users.

This repository contains only the java class files for my 2nd year object orientated program module, utilising the Javafx package and sql connector to create a graphical application with database capabilities. The application was also managed with "Maven", however those files have not been added as I did not write them myself. Needless to say these files will not run the application themselves, and for that I apologise, but even if they did I would have to running a database at all times for there to be anything of worth doing with it. I hope however these files still demonstrate my skills with the language
